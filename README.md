# DeckPad — Toshiba AT200 як сенсорний Stream Deck

Планшет показує сітку кнопок. На ноутбуці (Windows 10) програма DeckPad дозволяє
вибрати, що робить кожна кнопка. Зв'язок іде **кабелем USB**, інтернет не потрібен.

## Збірка (GitHub Actions)
1. Створіть репозиторій на GitHub і завантажте в нього вміст цієї папки
   (у корені репозиторію мають лежати `.github`, `android`, `windows`, `README.md`).
   Якщо папка `.github` не завантажилась, створіть файл `.github/workflows/build.yml` на сайті вручну.
2. Вкладка **Actions** → *Build DeckPad* → **Run workflow** (або просто зробіть push).
3. Після збірки завантажте артефакти:
   - `DeckPad-tablet-apk` → `app-debug.apk` (встановити на планшет)
   - `DeckPad-windows` → папка з `DeckPad.exe` та `adb.exe` (скопіювати на ноутбук)

## Налаштування планшета
1. Встановіть `app-debug.apk` (дозвольте встановлення з невідомих джерел).
2. **Налаштування → Параметри розробника → Налагодження по USB** (увімкнути).
   Якщо розділу немає: Налаштування → Про планшет → 7 разів торкніться «Номер збірки».
3. Відкрийте додаток DeckPad. Він чекатиме на ноутбук.

## Налаштування ноутбука
1. Підключіть планшет USB-кабелем. На планшеті підтвердьте запит «Дозволити налагодження по USB».
2. Запустіть `DeckPad.exe` (adb.exe має лежати поруч). Угорі має з'явитись «● Tablet connected».
3. Клацайте клітинки в сітці й налаштовуйте кнопку: текст, колір, анімацію, дію.
4. Зміни одразу надсилаються на планшет і зберігаються (`%APPDATA%\DeckPad\config.json`).
   Кнопка «Test» виконає дію через 2 секунди.
5. Закриття вікна згортає програму в трей, кнопки продовжують працювати.
   Повторний запуск `DeckPad.exe` повертає вікно. Вийти повністю: правий клік на іконці в треї → Exit.

## Дії кнопок
- **Hotkey** — `Ctrl+Shift+M`, `Alt+F4`, `Win+D`, `F5`… (натискання тримається 70 мс).
  Якщо програма (наприклад Mirillis Action) запущена від адміністратора, запускайте DeckPad теж від адміністратора.
- **Type text** — друкує текст (будь-якою мовою).
- **Run program** — запуск .exe з аргументами. **Open URL** — відкриває сайт.
- **Media key** — Play/Pause, наступний/попередній трек, гучність.
- **System** — Shutdown, Restart, Hibernate, Sleep, Lock, Log off, Switch user.
  - Hibernate працює, якщо гібернація увімкнена (один раз у командному рядку від адміністратора: `powercfg /h on`).
  - Switch user веде на екран входу (сеанс і програми залишаються працювати). На Windows Home команди `tsdiscon` немає, тоді відкриється екран блокування.
- **Macro** — послідовність команд, по одній у рядку. Рядки з `#` — коментарі.

### Команди макросів
| Команда | Приклад | Що робить |
|---|---|---|
| `key` | `key Ctrl+N` | натискає клавішу чи комбінацію |
| `text` | `text Привіт` | друкує текст |
| `wait` | `wait 500` або `wait 1.5s` | пауза |
| `focus` | `focus Vegas` | виводить на передній план вікно, у заголовку якого є цей текст |
| `run` | `run "C:\Program Files\App\app.exe" аргументи` | запускає програму (шлях з пробілами беріть у лапки) |
| `url` | `url https://example.com` | відкриває сайт |
| `media` | `media PlayPause` | медіаклавіша |
| `system` | `system hibernate` | системна функція |

Приклад (підлаштуйте під свою версію програми, паузи залежать від швидкості ноутбука):
```
# Новий проект у Sony Vegas
focus Vegas
wait 300
key Ctrl+N
wait 1000
key Enter
```
Поки макрос виконується, повторні натискання кнопок ігноруються.
Кліків мишею в макросах поки немає, тільки клавіші.

## Вигляд кнопок
- **Колір** лишається завжди; поле **Picture (JPG, PNG, GIF, MP4)** показує фото, GIF або відео замість суцільного кольору (текст кнопки лежить поверх).
  Фото підходить і для кнопок, і для фону.
  Файли пересилаються на планшет кабелем (до 25 МБ на файл) і зберігаються там, тож анімації працюють і без ноутбука.
  - GIF найкраще підходить для кнопок. MP4 для планшета важкий: одночасно програється максимум 3 відео (фон теж рахується), решта кнопок лишаються кольоровими.
  - Для MP4 краще H.264, невеликого розміру.
- **Формат кнопок** (друга панель зверху):
  - *По розміру екрана* — кнопки заповнюють весь екран планшета.
  - *1:1* — квадратні кнопки середнього розміру з невеликою відстанню, по центру екрана. Тут з'являється **Background**: суцільний колір або відео/GIF на весь екран за кнопками.

## Планшет
- Угорі посередині — годинник ГГ:ХХ за українським часом. Час береться з ноутбука (зона «FLE Standard Time»), тож годинник правильний, навіть якщо в планшета збитий час.
- Кнопка **«Відключення»** справа вгорі завжди на місці. Натискання перекриває весь інтерфейс чорним екраном і знижує яскравість; дотик у будь-яке місце повертає інтерфейс.

## Якщо ноутбук не бачить планшет
- Windows 10 зазвичай сам ставить драйвер ADB. Якщо ні, встановіть Google USB Driver.
- Спробуйте інший кабель (потрібен кабель з передачею даних) і інший USB-порт.
- Запасний варіант без adb: на планшеті увімкніть **USB-модем** (USB tethering),
  у DeckPad зніміть галочку «USB cable (adb)» і введіть IP планшета в цій мережі
  (зазвичай 192.168.42.129).

## Як це влаштовано
Планшет слухає порт 38200. DeckPad на ПК підключається через `adb forward`,
надсилає розкладку кнопок у JSON, час і (на прохання планшета) файли анімацій.
Планшет шле назад номер натиснутої кнопки. Вся логіка дій виконується на ноутбуці.
